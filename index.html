    Your files, on your device

    File contents, filenames and converted results are not sent to FileHush or another conversion service. The app keeps only your current job in page memory and does not save file data or history in browser storage. Clear releases app-held previews and results; browser memory cleanup timing is outside the app’s control.

    The website host receives ordinary page and asset requests, including connection information. Your browser manages downloads and may use memory or disk. This site cannot protect against a compromised device, browser extension, or modified website code.

    No installation is required. Conversion works after the relevant tool resources have loaded if the connection is lost. Offline visits and reloads are not guaranteed. Save outputs explicitly; leaving or reloading the page clears the current job.

    Re-encoding may change metadata and color profiles. Lossy formats can lose detail; output can be larger than input. Document layout is approximate. This is not an archival or certified metadata-removal tool.
